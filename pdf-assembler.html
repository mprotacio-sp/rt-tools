2Assemble the final PDF

  1. Download your project folder from SharePoint — most browsers will save it as a single .zip file automatically.
  2. Drag that .zip file into the box below, or click the box to choose it from your computer.
  3. The tool finds every PDF whose file name starts with a two-digit number and an underscore, and puts them in that order.
  4. Review the lists that appear — one for files that were merged, one for anything that was skipped.
  5. Click Download merged PDF to save the finished document.

Only files named like 01_Cover.pdf, 02_Position.pdf, 03_Contact.pdf are included. Anything without a leading two-digit number and underscore is left out and listed separately.
